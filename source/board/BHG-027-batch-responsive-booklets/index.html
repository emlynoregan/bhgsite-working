Goal

Apply the validated reader converter to all 38 recovered booklets, giving the new Booklets detail pages a complete responsive reading edition, with image assets and page anchors.

Source

  • Reader prototype ticket.
  • Working-site plan and structured catalogue.

In scope

  • Batch convert all 626 source HTML pages, keeping unique source mapping.
  • Handle multi-column layouts, pictures, captions, maps, references and pagination with documented per-booklet correction files.
  • Reconcile different editions and catalogued/actual page counts without mislabelling.
  • Automated text/image/link validation and mobile/desktop sample visual inspections for each booklet.
  • Update the catalogue with reader status and work requiring human editorial review.

Out of scope

  • Uploading binary source/PDF assets.
  • Publishing to Preview or Real, or inventing missing The Burra Institute content.

Acceptance criteria

  • 38 responsive reader editions built. All 76 Chromium mobile/desktop checks passed without horizontal overflow.
  • All 626 pages matched to original Publisher PageID order; stable page anchors verified.
  • Independent source validation: 4,686 source text pieces and all 650 image uses accounted for byte-for-byte; no missing files. Publisher credits remain in source text. Caption/figure association and image-credit editorial correctness require BHG-029 proofing.
  • Full audit and per-title QA: 16 data tables, 122 predominantly image-based pages, two export-blank candidates, and editorial exceptions explicitly recorded and handed to BHG-029.
  • All original Publisher and native PDF copies unchanged; reader files generated solely in the separate D: working area.

Stop and ask

Review the converter against the pilot and design first. If exceptions dominate, revise the design rather than ship hundreds of brittle one-off pages.

Completion notes

Completed technical conversion 19 October 2026. See full batch report, machine QA and responsive paths added to artifact inventory.

  • Converted 38/38 recovered titles: 626 pages; independently matched 4,686 exported text pieces, 650 image uses byte-for-byte, 16 tables and all page IDs/anchors.
  • All 76 browser viewport tests passed at 390px mobile and 1200px desktop. Image dimensions reserve layout space, each image opens at full resolution, and image-based pages allow individual illustration rotation.
  • 122 mostly image-based pages, image credits, caption associations, multi-column reading order and two possible blank-export pages remain for BHG-029 editorial proofing. The source text/image integrity check does not constitute proofread historical publication. BHG-028 must not activate unapproved reader/download links.
  • No deployment or publication to Working, Preview or Real; original archives untouched.
