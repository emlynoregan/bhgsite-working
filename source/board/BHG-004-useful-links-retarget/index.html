Goal

Every broken Useful Links listing on Preview has a working URL, a credible alternative, or a Wayback snapshot — then an editorial keep / retarget / delete with Barbara.

Source

  • 4 September meeting notes — Decision: “For every broken class — NXDOMAIN, 404, 403, TLS, 200-to-homepage — research a working link, a credible alternative, and Wayback. 403 in this context is usually ‘broken,’ not a real permission wall (Goyder cemetery named). Editorial delete vs retarget comes after that research.”
  • Useful Links inventory — research pass already recorded 4 September. Casino slice is BHG-001. Remaining: retarget obvious current URLs; Wayback Cornish / RootsWeb / Leadbeater / Ships List before any delete; confirm 403s in a browser.
  • 28 August meeting notes — Barbara: nine dead genealogy links; Goyder cemetery 404; shipping mostly dead (she would delete several; Emlyn wanted Wayback because Cornish arrivals matter); SE / Port Adelaide / Yorke Peninsula groups dead; History row “none of the ones they named work.”

Scope

In scope

  • Apply the inventory to Preview: retarget, Wayback, or remove, following the meeting rule.
  • Update the inventory when Preview changes.
  • Flag rows that still need a keep/delete call, and record Emlyn’s first-shot decisions here for the group to review.

Out of scope

  • The six casino hrefs (BHG-001) if that ticket is still open — do it first.
  • Inventing new “useful” directories that were never on the page.

Acceptance criteria

  • Preview Useful Links has no remaining casino or known-dead href from the 4 Sep inventory without a replacement, Wayback, or an explicit “dropped” note.
  • Cornish-arrival / shipping rows are Wayback or retargeted before delete.
  • Inventory page on the working site matches what Preview now does.
  • Live on Preview. Real not touched.

Stop and ask

Do not dump the whole shipping list because it is tedious. Emlyn is taking a first shot at keep / Wayback / drop; each call is recorded below for the group (and Barbara) to review. Do not treat these as final until that review.
