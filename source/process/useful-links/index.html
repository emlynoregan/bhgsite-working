Meeting context

Barbara’s punch list on 28 August (see the meeting notes): nine dead genealogy links; Cyndi’s List / RootsChat dated; Goyder cemetery records 404; SA cemeteries / Cemeteries SA parked; shipping mostly dead (she would delete several; Emlyn wanted Wayback because Cornish arrivals matter); SE / Port Adelaide / Yorke Peninsula groups dead; History row “none of the ones they named work”; second war-memorials link dead.

This check agrees on the shape of that list. A few hosts that looked dead on the projector now answer (History Trust, FamilySearch, AWM). Several familyhistorysa.org paths return 200 but are not the pages the labels promise.

Not a cutover blocker. Parity with burrasa.net is enough. Cleaning this list is still worth doing because a wall of 404s is worse than a short, good list — and because several hrefs now send people to gambling pages.

Working rule from the meeting, still the right one:

  • Delete dated directories and one-off forum threads unless someone will use them.
  • Wayback / retarget shipping and Cornish-arrival sources before deleting.
  • Keep high-quality live sites (FamilySearch, Genealogy SA home, AWM, History Trust, SLSA, Burra Community Library catalogue).
